# Support

CodeBridge is currently beta software for macOS 14 or newer, on Apple Silicon and Intel Macs.

Before filing an issue, launch CodeBridge and run the built-in diagnostics or `npm run doctor` from a development checkout. Never include API credentials, connector credentials, private repository contents, local audit logs, or sensitive project files in a public issue.

For bugs, include the CodeBridge version, macOS version, whether the failure is app startup / ChatGPT connection / project access / command execution, and a minimal reproduction using a disposable project where possible.

Security issues should not be posted as ordinary public issues; use the repository's private security reporting (Security → Report a vulnerability).
